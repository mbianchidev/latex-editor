# Documentation

[Project overview](../README.md)

LaTeX Editor is a browser-based editor backed by a local TeX compiler and SQLite project
storage. Start with installation for a first run, then the user guide for an actual project.

## For users

| Guide | Covers |
|-------|--------|
| [Installation](installation.md) | Platforms, prerequisites, first run, upgrades, and stopping |
| [User guide](usage.md) | Projects, editing, PDF export, GitHub sync, and LaTeX examples |
| [Configuration](configuration.md) | All application environment settings, limits, storage, and backups |
| [Troubleshooting](troubleshooting.md) | Startup, compilation, imports, persistence, and GitHub errors |
| [Accessibility](../ACCESSIBILITY.md) | Contribution target, current limitations, and reporting barriers |
| [Support](../SUPPORT.md) | Existing help channels and what to include in a report |
